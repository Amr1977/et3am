# ET3AM-011: Donation Requests Feature

**Trello:** N/A
**Status:** DONE

## Description
Users can post donation requests (asking for food for their family), including number of members and location on map. Donors can fulfill one or more meals on a request. The request is updated in real-time and stays open until all meals are fulfilled. Donor-requester chat is supported.

## API Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/requests` | List requests (filter, proximity) |
| GET | `/api/requests/my-requests` | User's own requests |
| GET | `/api/requests/my-fulfillments` | Requests donor has fulfilled |
| GET | `/api/requests/:id` | Single request detail + fulfillments |
| POST | `/api/requests` | Create request |
| PUT | `/api/requests/:id` | Update request (owner) |
| DELETE | `/api/requests/:id` | Cancel/delete request |
| POST | `/api/requests/:id/fulfill` | Donor fulfills meals |
| GET | `/api/chat/request/:requestId` | Get request chat messages |
| POST | `/api/chat/request/:requestId` | Send request chat message |
