# ET3AM-013: Fullscreen Map on Interaction

**Trello:** [Link](https://trello.com/b/et3am-project)
**Status:** DONE

## Description

Maps auto-expand to fullscreen (covering entire viewport over navbar and footer) when user interacts with them (pan, zoom). Currently maps required explicit "Fullscreen" button click.

## Acceptance Criteria
- [x] Home page hero map auto-fullscreens on first pan/zoom interaction
- [x] Donations page map auto-fullscreens on first pan/zoom interaction
- [x] Escape key and ✕ close button exit fullscreen
- [x] Fullscreen only triggers once (not repeatedly)
- [x] DonationsMap embedded fullscreen buttons work when parent controls fullscreen state

## Learnings
- Leaflet map `dragstart` and `zoomstart` events are reliable for detecting user interaction without false positives
- Using `useRef` with a `hasTriggered` flag ensures auto-fullscreen only fires once per session
- DonationsMap had a silent bug: its Fullscreen/Exit button only controlled `internalFullscreen`, which was ignored when parent passed `isFullscreen` prop. Added `onFullscreenChange` callback to fix.
